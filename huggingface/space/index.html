METHOD & LIMITATIONS

Evidence, with context.

CuratorKIT cleaned and deduplicated the prompts. AuditKIT ran both conditions against Cohere’s public Tiny Aya Space. The guided run added a system instruction; the model weights were not changed. The 18-case challenge set was authored after that instruction was chosen.

Both sets are small, public and unvalidated, and outputs have not been independently reviewed. Use this interface to inspect the logs, not to make claims about model safety.
